# fusezone

Fuse config/zone key checks for twelve-factor services.

**Site:** https://theworker02.github.io/fusezone/

## Install / run

```bash
git clone https://github.com/theworker02/fusezone.git
cd fusezone
node src/cli.js
node --test
```
